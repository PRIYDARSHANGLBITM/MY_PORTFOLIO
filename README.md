# Priy Darshan Portfolio

Personal portfolio website built using React, Vite, GSAP, and CSS.

## Live Demo

🚀 Vercel Deployment:

https://my-portfolio-five-chi-32.vercel.app/

## Features

- Responsive Design
- Smooth GSAP Animations
- Projects Showcase
- GitHub Contribution Calendar
- Contact Form with Formspree
- Social Media Links

## Tech Stack

- React.js
- Vite
- GSAP
- CSS3
- Formspree
- Vercel

## Installation

```bash
git clone https://github.com/PRIYDARSHANGLBITM/MY_PORTFOLIO.git
cd MY_PORTFOLIO
npm install
npm run dev
```
